# 蝈蝈听书 · 云端真人人声 + 用户自助付费 —— 技术方案 v2

> 状态：**Worker 骨架已建成**（`worker/` 目录：全路由 + 额度/限流/日预算熔断 + Mock 供应商，单测 65/65），
> 等厂商 key 进入 M1 联调。路线不变（A：云端 TTS + 支付闭环）。
>
> **v2 变更（选型复盘，采纳外部评审）**：
> 1. **供应商改序**：百度长文本 > 腾讯通用 > 火山（仅音色试听）——原「火山流式优先」废弃；
> 2. **四条硬限制**写死进选型（见 §7.1）：非流式完整音频优先 / Key 只在代理后 / 自记额度硬熔断（已实现）/ EdgeSpeech 排除；
> 3. **本地默认 = sherpa v3**（真机 A/B：Piper=「鸟语」已淘汰，模型为 VITS aishell3）；
>    云端在手机上的定位 = 补齐「听得懂 + 流畅」（sherpa 手机 RTF≈3 会断档），亮屏预合成、熄屏纯本地。
>
> 目标一句话：**用户视角 = 点一下 → 微信/支付宝付钱 → 直接听真人人声**；
> 开发者视角 = Cloudflare Worker 做后端（验付款、发通行证、代理合成、扣额度、防刷），
> 厂商 key 永远只存在服务端；你只需要出面做注册的事（见 §12）。

## 1. 目标 / 非目标

**目标**
- 真人级音色、整段合成（本地引擎到不了的天花板；**不追流式**，见 §7.1）。
- 不熟练用户友好：无密码、无注册页、不离开应用完成付费。
- 零垫资起步：先用厂商免费额度跑通，再收款。
- 服务端持 key、额度防刷、文本上云显式授权（沿用现有隐私开关）。

**非目标（本期不做）**
- 完整账号体系 / 社交 / 多租户（阶段二再说）。
- 自建或微调语音模型（本地 Kokoro wasm 因 RTF≈3.2 已搁置，WebGPU 路线另行记录）。
- 微信官方支付（需个体户资质，列为 M4 升级项）。
- 流式对话式 TTS（熄屏 JS 冻结、WS 被杀，架构上用不到）。

## 2. 总体架构

```
手机/电脑浏览器  https://tinttxt.pages.dev（纯静态，已有）
   │  现有 cloud-http 适配器：POST {text, voice, rate, format:'wav'} + Bearer <通行证token>
   ▼
Cloudflare Worker  tinttxt-api.<你的子域>.workers.dev（骨架已建成，免费额度够个人用）
   ├─ /api/tts        代理合成：验通行证 → 扣额度 → 调厂商 → 包装 WAV 返回（非流式整段）
   ├─ /api/voices     音色列表（Worker 侧缓存）
   ├─ /api/trial      免费试听（每设备每天 N 句，免通行证）
   ├─ /api/me         通行证状态 / 余额
   ├─ /api/pay/create     创建订单（虎皮椒）
   ├─ /api/pay/webhook    支付回调（MD5 验签 → 幂等 → 自动激活当前设备）
   └─ /api/activate       兑换码 / 订单号激活（换设备恢复、人工兜底）
   存储：Workers KV（通行证、额度计数、限流计数、订单）
   密钥：wrangler secret（厂商 key、支付 secret）—— 永不下发到前端
   ┌──────────────────────────────┐        ┌──────────────────┐
   │ 百度长文本 / 腾讯通用（主力）  │        │ 虎皮椒（个人收款） │
   │ 火山（仅音色试听）            │        └──────────────────┘
   └──────────────────────────────┘
```

- **同一账号、同一套凭据**：你的 CF 账号已有 Workers（panmian-worker 在用），新建一个即可。
- **COEP 无影响**：API 与页面同源（或独立子域走 CORS 白名单），`credentialless` 不拦同源请求。

## 3. 与现有应用的接入（协议已兼容，改动很小）

现有 [cloud.js](../src/layers/playback/tts/cloud.js) 协议：
`POST endpoint`，JSON `{text, voice, rate, format:'wav'}`，`Authorization: Bearer <apiKey>`，返回音频 Blob。

→ **Worker 按此协议实现，前端几乎零改动**：
1. 设置 → 云端 TTS：端点填 Worker 地址，apiKey 填通行证 token（免费档留空，走设备头）。
2. 应用侧小改（我做）：
   - 音色列表从 `GET /api/voices` 拉取（现在是写死的"云端默认音色"）；
   - 「真人音色」入口卡片：**3 句免费试听 → 开通引导（扫码/一键付款）→ 余额显示**；
   - 请求头带 `X-Device-Id`（匿名 UUID，存 localStorage）用于免费额度与付款自动绑定；
   - 隐私提示沿用现有 `cloudTtsEnabled` 显式开关文案（文本将发送至云端合成）。
3. **音色试听/挑音色按钮（v2 新增，M1 小项）**：走 Worker 代理、只发 200 字、把候选音色摆一起 AB 听，
   选完把音色 ID 存进设置——**不做整章链路**，整章是 M2 之后按 §7.4 滚动预合成。

**硬性技术要求**：
- 厂商必须能输出 **PCM/WAV**（播放层按 WAV 头做句级时间轴合并；只给 MP3 会走降级路径、时间轴错乱）。
  Worker 负责把裸 PCM 包装成标准 44 字节头 WAV。这是 M1 的第一个验收项。
- **非流式/异步整段优先**（v2）：单请求给完整音频文件，或异步任务返回完整音频下载地址。

## 4. Worker 后端设计

| 路由 | 方法 | 鉴权 | 逻辑 |
|---|---|---|---|
| `/api/voices` | GET | 无 | 返回厂商音色表（KV 缓存 24h） |
| `/api/trial` | POST | deviceId + IP 限流 | 每设备每天 N 句试听（≤50 字/句），走免费额度 |
| `/api/tts` | POST | Bearer 通行证 **或** X-Device-Id（免费档） | 长度校验 → 限流 → 熔断 → 额度扣减 → 调厂商 → 包 WAV → `X-Quota-Remaining` |
| `/api/me` | GET | deviceId | 通行证状态、今日已用、套餐余量 |
| `/api/pay/create` | POST | deviceId | 建单（虎皮椒），返回支付 URL/二维码（M2，当前501占位） |
| `/api/pay/webhook` | POST | **MD5 验签** | 幂等落单 → 发通行证（绑定下单时的 deviceId）（M2） |
| `/api/activate` | POST | 兑换码/订单号 | 跨设备恢复、人工兜底（M2） |

**KV 键设计**
```
pass:<token>      → {deviceId, plan, exp, usedTotal, day:{YYYYMMDD: chars}}
order:<tradeId>   → {token, status, paidAt}        （webhook 幂等）
budget:<YYYYMMDD> → 全局已用字符数（熔断计数）
free:<device>:<YYYYMMDD>  → 免费档日计数
rate:<ip>:<YYYYMMDDHHmm>  → 分钟级限流计数
trial:<device>:<YYYYMMDD> → 试听句数
cfg:voices        → 音色表缓存
```

**限流与熔断（默认值，全部做成 Worker 配置可调；纯函数已单测）**
- 单请求 ≤ 500 字；每 IP ≤ 10 次/分钟；每设备每日字符上限（默认 3600 字 ≈ 15 分钟）；
- **全局日成本熔断**：当日消耗超过预算（默认 50 万字）→ 自动关闭云端（503），次日恢复，**绝不指望厂商提醒**；
- KV 免费额度：10 万读/天、1 千写/天、1GB 存储；Workers 10 万请求/天 —— 个人规模绑绑有余（[官方定价页](https://developers.cloudflare.com/kv/platform/pricing/)，以页面为准）。

## 5. 用户身份与开通流程（关键：不给不熟练用户添麻烦）

**阶段一（本期，零资质）：设备通行证 + 恢复码**
1. 应用首启生成随机 `deviceId`（localStorage），全程无密码无注册页。
2. 点「开通真人音色」→ 带 deviceId 创建订单 → 扫码付款 → **回调自动激活当前设备**（用户回到应用即可用，无感）。
3. 同时发一串 **8 位恢复码**：换手机 / 清数据时输入恢复；也兼容"付完钱把订单号发给你"的人工兜底。
   > 这正是社区验证过的通行做法（设备码当用户凭证 + 服务端验签落库），见[个人收款接入讨论](https://www.locdd.com/t/topic/71694/17)。

**阶段二（规模化后可选）**：微信扫码登录（需微信开放平台资质）或手机号验证码登录（短信通道需实名+签名报备）。阶段一不需要。

## 7. 云端 TTS 选型（v2 重排：按我们的架构，不按语音助手的直觉）

### 7.1 四条硬限制（选型前提，全部采纳）

| # | 限制 | 依据 |
|---|---|---|
| 1 | **非流式完整音频优先**：要"一次给整段"或"异步任务返回完整文件"，不要流式 | 熄屏后 JS 冻结、WebSocket 被杀；亮屏预合成整章 → 本地缓存 → 熄屏只播文件 |
| 2 | **Key 永远只在代理（Worker）后** | CORS 不是保险箱，F12 即可看到前端一切；Key = 以你账号身份花钱 |
| 3 | **自记额度 + 硬熔断，绝不指望厂商提醒**（已实现） | 免费包扣完自动进计费流程、不会自动停；我方日预算熔断 503 回落本地 |
| 4 | **EdgeSpeech 网页直连排除** | 浏览器 UA 校验拒 Chrome/华为浏览器（改不了 UA）；且 2026-10-10 起老端点被微软区域性 403、生态被迫换端点追 token（[rany2/edge-tts#490](https://github.com/rany2/edge-tts/issues/490)）——月更维护陷阱，连 Worker relay 都不作依赖 |

### 7.2 厂商分档（数字以控制台为准，接入前复核）

| 档 | 厂商 | 理由 |
|---|---|---|
| ✅ **主力①** | **百度 · 长文本在线合成** | 官方原话"最高支持 **10万字** 一次性合成、**异步返回音频**、支持下载，适用于**阅读听书**"（[官方](https://ai.baidu.com/tech/speech/long_tts)）——与"整章预合成"结构性吻合；Worker 侧 create + 轮询 query 两步；支持 wav 输出。免费额度：实名/认证后控制台领取（价格页口径"企业认证领10万字"，个人额度以控制台为准） |
| ✅ **主力②** | **腾讯云 · 通用语音合成（非流式）** | **800万字符**（精品音色）、3个月、一次性领取（[官方FAQ](https://cloud.tencent.com.cn/document/product/1073/34090)）；但**免费包不含长文本接口**、单次建议 ≤300 字 → Worker 分段合成 + WAV 拼接（util 已备）；SSML 可自定义数字读法 |
| ⚠️ **仅试听** | **火山 · 豆包** | 音色最自然（挑音色/AB 对比最佳），但免费仅约 **2万字符**（半年）且是 WS 流式 → **只做200字试听按钮**，不作整章主力 |
| ❌ 排除 | 阿里云限时包 / MiniMax / ElevenLabs | 30天下线的活动包；境外墙 + 延迟，华为国内网络不稳 |
| ❌ 排除 | EdgeSpeech 网页直连 / 任何前端硬编码 Key | 见 §7.1 第4条 |

**免费档最省用法（v2 修订：按句缓存，不整章预合成）**：
本项目单用户单本，无重复命中规模，「热门书预合成 CDN」只会浪费额度（规则4）。
正确策略：**缓存粒度=句**（`audio-cache.js`，键=md5(text+voice+rate)），回退/重听/跳章/改语速回切全命中；
前瞻队列 3~5 句，首块 3~8 秒出声；**禁止整章一次性合成**（规则2）。
额度计数到阈值自动切回本地离线模型，永不产生账单。

### 7.3 成本账（决策关键，听书是重度场景）

- 中文朗读 ≈ 4 字/秒 → **1 小时 ≈ 1.4 万字**。
- 百度长文本价格页口径"万字低至0.5元"量级 → **≈0.7 元/小时**（以官方计费页为准）。
- 火山资源包 ≈ 0.28 元/千字 → ≈4 元/小时（若日后转正）。
- 结论：**免费档必须限字数**；付费档必须满足 `售价 ≥ 3 × 期望人均成本`，并配每日上限。定价样例（供拍板）：
  - 免费：每天 15 分钟（≈3600 字，优先用厂商免费额度承载）；
  - 月卡：¥19.9~39，**每日上限 1 小时**（防刷命门）。

### 7.4 与本地引擎的关系（定位写死）

- **默认主力仍是本地离线**：sherpa（吐字清晰、零 Key、零额度、本地合成时文本不出设备、熄屏最稳、不怕厂商改协议）。
- **云端只做「亮屏前台 + 显式开关 + 按章预生成」的加分层**——在手机上它同时补掉 sherpa 的断档（RTF≈3），
  让"听得懂"和"流畅"同时成立；额度用尽/熔断即回落本地，体验无缝降级。
- Piper 不再作为任何默认（真机 A/B 实测发音不可懂）。

## 8. 隐私与合规

- 文本上云 = 现有 `cloudTtsEnabled` 显式开关 + 隐私提示（已具备）；Worker **不落库用户文本**，日志只记字数与耗时。
- 厂商侧实名是开通义务；我们不收集手机号/姓名，只有匿名 deviceId（最小化收集）。
- 生成音频需标注"AI 合成、非真人录音"，**禁止冒用他人声音**；声音复刻不用别人的音色。
- 顺手核对厂商生成音频的**再分发条款**——别把"试听"变成"分发"。
- 聚合收款走各平台虚拟商品条款；正式商用前再核对一遍。
- 朋友间互传、纯离线、不收集信息的主场景属个人分享，风险可控。

## 10. 风险清单

| 风险 | 等级 | 缓解 |
|---|---|---|
| 厂商价格/免费额度调整 | 中 | 全部金额做成配置；免费额度优先用"新用户/免费包"承载；熔断兜底 |
| 厂商只出 MP3、不出 PCM/WAV | 中 | **M1 首个验收项**，不满足就换厂商（百度/腾讯均声明支持 wav） |
| 聚合收款平台不稳定/跑路 | 中 | 双通道（虎皮椒自动 + 订单号人工），资金不过我们手 |
| deviceId 被清绕过免费额度 | 中 | 服务端 IP 限流 + 日熔断兜底（不依赖 deviceId 唯一性） |
| Workers/KV 免费限额 | 低 | 个人规模够用，超了有明确报错（升级付费 $5/月） |
| 有人拿云端接口刷文本生成 | 低 | 单请求长度 + 频次 + 每日总量三层限制 |
| 非官方通道（如日后考虑 EdgeSpeech）易变 | 高 | **本方案不依赖任何非官方端点**（已排除） |
