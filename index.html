      发音试听 A/B（真机音质定性）

      同一句固定文本分别用两个引擎合成并播放 —— 用耳朵判断：Piper 是否可懂（是否"鸟语"）、 sherpa 是否吐字清晰。要求两个引擎的模型都已下载（设置页有下载按钮）。

      后台播放测试引导

      1. ① 开始播放 预期：状态徽标显示「播放中」，正文逐句高亮前进，进度条持续走动。
      2. ② 锁屏 ≥10 秒，并跨过一个音频块（约 1–2 分钟处） 预期：解锁后自动继续播放；MediaSession 显示书名与暂停键；日志里心跳先停止、恢复后继续刷新；块索引已推进（跨块成功）。
      3. ③ 切到微信停留 60 秒 预期：返回本页后播放继续（若被系统打断会提示「点继续恢复」，点播放即可），进度不丢失。
      4. ④ 连接蓝牙耳机 预期：耳机的播放/暂停、上一句/下一句键可控；锁屏卡片同样可控。

      华为 / EMUI 白名单设置路径

      • 手机管家 → 应用启动管理 → 关闭「自动管理」→ 手动允许「自启动 / 关联启动 / 后台活动」。
      • 设置 → 电池 → 受保护应用 → 把浏览器加入名单。
      • 浏览器设置 → 关闭「省流加速 / 云端加速 / 极速模式」。
      • 浏览器实验室 → 媒体控制 → 允许「网页后台播放音频」。
      • 系统设置 → 添加桌面快捷方式时注意：华为浏览器「添加到桌面」可能只是网址快捷方式（普通书签），不等于 PWA，离线打开可能失效。

      限制清单

      • 系统朗读预览不满足熄屏约束：本地模型未下载时临时用系统朗读，切后台 / 锁屏会被中断，下载本地模型后即消失。
      • 本地模型首次需联网下载：标准档 63MB / 省流档 21MB，下载后完全离线，本地合成时文本不出设备。
      • 云端 TTS 默认关闭：开启需隐私确认；开启后每段文本会发送到你配置的云端服务器。
      • iOS / Safari 能力缺失：MediaSession 锁屏控制、Wake Lock 可能不可用，界面会显示「不支持」而不是报错。
      • 页面被冻结：长时间后台时浏览器可能冻结 JS，心跳停止即为证据；需按上面的白名单路径放行。
      • 音频导出：未缓存的块会在导出现场合成（整本导出耗时较长，可随时取消）；只有全书无可朗读内容时才提示「没有可导出的音频」。
      • 跳行规则 / 章节正则 / 标点策略：修改后需重新打开书籍才会重建句子结构。
      • 手动标记章节：在当前会话内生效并写回书库；重新打开书籍时若正则仍能识别，会按章节正则重新切分。
